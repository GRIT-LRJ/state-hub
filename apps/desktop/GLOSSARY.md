# 桌面管理

桌面端帮助用户接入来源、设置输出和规则，并观察本地运行情况。

## 输入与输出

**来源定义**：约定一种来源可以报告哪些状态和事件，以及消息的含义与格式。

**接入方（生产者）**：向 State Hub 报告信息的具体发送方。接入凭证有效仅表示具有报送权限，不表示正在运行或持续上报。
_Avoid_: 在线来源（仅凭授权状态推断时）

**当前状态（状态声明）**：某个接入方、作用域和信号当前报告的事实，不是历史事件列表。

**输出**：一个已配置的设备或服务目标。输出可以先独立存在，之后再关联规则。
_Avoid_: 规则、通知记录

**联动规则（绑定）**：规定哪些输入在满足哪些条件时，以什么内容触发哪个输出。

**当前输出（输出投影）**：根据当前状态与规则决定的、某个输出通道此刻应呈现的状态。
_Avoid_: 已执行结果、已发送通知

**投递**：把一个输出动作交给驱动执行的任务。成功表示驱动报告调用成功，不表示接收人已阅读。

**失败归档（死信）**：已经停止自动重试的投递任务。

## 配置与操作

**未保存编辑**：用户正在修改、尚未应用的一次输出或规则编辑。
_Avoid_: 跨栏目统一草稿

**配置版本**：一套已记录的输出与规则配置；回滚恢复整套配置，并产生一个新版本。

**审阅并应用**：确认本次操作的变化及影响，再使这次配置修改生效。

**凭据引用**：供配置指向已保存密钥的名字，不是密钥本身。

**确认此版本**：确认已经看到某次状态；尊重确认的规则可以停止对这次状态的提醒，新版本仍需单独确认。

**全局暂停**：暂停输出而继续接受输入。恢复时重算当前状态，不补发暂停期间被抑制的事件效果。
