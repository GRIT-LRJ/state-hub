# 桌面界面设计

本设计来自 2026-10-12 的 grill-with-docs 逐题访谈；用户已确认以下决定，并授权实施。

## 导航与用途

单窗口、左侧固定六栏、右侧工作区，启动进入概览。整体参考 Clash Verge Rev 的紧凑桌面布局；分组、就地说明参考 VS Code 设置。沿用浅色与紫色强调，减少大卡片和装饰。保持默认 1120×760、最小 760×560 可操作。

- 概览：运行摘要；当前状态与当前输出使用选项卡。状态确认精确到版本；输出投影不等于设备已执行。
- 来源：接入方列表、添加、轮换或撤销 Token。解释授权与在线的差异；提供 Codex 分步接入。
- 输出：独立设置设备或通知服务。显示关联规则数；无规则是合法配置。就地保存必要密钥。
- 规则：以“来源 → 条件 → 输出”摘要显示。编辑分为触发条件、执行动作、高级选项；保留所有现有条件、映射和参数能力。
- 诊断：最近投递与支持包两个选项卡。按需加载最多 500 条脱敏投递，支持状态筛选；范围有限，不等于完整死信列表。支持包导出前审阅清单与脱敏范围。
- 设置：凭据、配置版本、关于三个选项卡。更新入口仅在运行环境支持时显示。

## 操作与反馈

输出和规则每次独立编辑、审阅、应用。切栏保留未保存编辑；应用当前操作不提交其他栏目内容。更换编辑对象前可以继续原编辑或明确放弃。真正退出应用后不恢复未保存编辑，隐藏到托盘继续保留。

删除被规则引用的输出必须先处理关联规则。预览后改动或基线变化需要重新审阅；断线禁用服务操作但保留编辑内容。加载、断线、空数据分别表达，不以无状态数据推断首次安装。

Codex 与 PushPlus 快捷配置按接入/密钥、输出、规则分步生效；每步可结束，已有对象可继续使用，不暗中轮换凭据或覆盖配置。

Token 和密钥操作即时生效，与输出配置是否应用分别反馈。一次性 Token 在独立弹窗展示，明确关闭后清除。密钥不写入浏览器持久存储；系统凭据管理不读回密钥。全局暂停和版本确认即时生效。

编辑使用工作区内视图，固定侧栏保留；长列表和详情在内容区域滚动。每页提供一句话用途，字段旁提供说明和示例。必填字段与错误始终可见，高级字段按需展开；支持键盘导航和清晰焦点。

## 各栏怎么理解与使用

**概览**回答“系统现在知道什么、准备做什么”。当前状态是来源最近报告的事实；当前输出是规则计算出来的期望结果。看到期望输出不等于设备已经执行，要到诊断查看投递。确认某个状态只针对显示的那一版本，后续新状态仍可能提醒。

**来源**回答“谁有权上报”。先为具体发送程序创建接入方，再把 Token 配置给发送程序；仅创建 Token 不会自动产生数据。Codex 引导准备授权与本机凭据，仍需 hook 实际上报。轮换 Token 后旧 Token 立即失效，发送端也需要更新。

**输出**回答“把结果交给哪个设备或服务”。例如虚拟输出用于观察联动，PushPlus 用于通知。先添加输出、填写参数、审阅并应用，到这里即可结束；没有规则的输出是合法配置。凭据引用只是系统凭据库中的名字，保存密钥不会替你应用输出配置。

**规则**回答“什么输入满足什么条件时，执行什么动作”。先选择来源和信号，再添加条件，最后选择已生效输出并配置内容映射。例如 `/content` 表示从输入中取 content 字段。高级选项控制确认、优先级和批处理；普通使用可以先保留默认值。审阅规则只应用这条规则，不夹带输出栏的未保存内容。

**诊断**回答“投递发生了什么、失败在哪里”。最近投递按需读取最多 500 条脱敏记录，可以筛选状态，但不能据此推断全部历史或完整失败归档。需要排障材料时，先查看支持包清单与脱敏范围，再决定是否导出文件。

**设置**集中放置低频管理。凭据用于保存或删除密钥，立即生效；配置版本用于审阅和恢复整套输出与规则，不恢复密钥或来源授权；关于展示应用说明和可用的更新入口。不要把配置版本与软件版本混淆。

初次体验可按“来源接入 → 虚拟输出 → 一条规则 → 概览 → 诊断”进行。每一步独立完成，也可以随时切栏；侧栏的小圆点表示该栏仍有未保存编辑。

## 验收场景

验证六栏与默认页、跨栏编辑保留、独立新增输出、仅修改规则、引用删除保护、并发冲突、预览失效、断线恢复、快捷流程中途结束、凭据即时生效、诊断范围与支持包预览。视觉检查默认及最小窗口、常用缩放、长名称和底部操作区；真实桌面生命周期与视觉结果分别记录。

## 接入创建的并发保护

新增接入方使用既有 `POST /api/v1/admin/producers` 的可选 `createOnly: true` 参数；服务端在事务内检查同名项，已存在时返回 `409 PRODUCER_EXISTS`，保留原 Token。省略参数的既有轮换调用保持兼容。这个小幅接口扩展用于兑现“新增不暗中轮换”的界面语义；仅在客户端先查列表不足以阻止并发创建竞态。数据库结构不变。
